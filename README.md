# Rinigier Project

## Backend
- Phoenix + Elixir
- REST API: CRUD użytkowników
- Import danych z GOV -> pliki wchodzą w skład repozytorium

## Frontend

- Lista użytkowników, filtrowanie, sortowanie, paginacja
- Dodawanie, edycja, usuwanie użytkowników
- TailwindCSS
